# 🧠 Probable

**Probable** is a decentralized prediction market built on Ethereum that allows users to create markets, trade YES/NO positions, and earn rewards based on real-world outcomes.

The project is being developed as a **portfolio-grade Web3 application**, with a strong emphasis on smart contract architecture, testing, security, and a modern frontend experience.

> 🚧 **Status:** Active Development

---

# 🚀 Overview

Prediction markets enable users to speculate on future events by purchasing shares in possible outcomes.

Probable brings this concept on-chain through Ethereum smart contracts, allowing transparent, decentralized, and verifiable market creation and settlement.

---

# ✨ Current Features

### Smart Contract

* ✅ Create prediction markets
* ✅ Buy YES shares
* ✅ Buy NO shares
* ✅ Resolve markets through a designated oracle
* ✅ Claim rewards after market resolution
* ✅ Cancel active markets
* ✅ Custom Solidity errors for gas efficiency
* ✅ Event-driven architecture
* ✅ Comprehensive unit testing (19 passing tests)

### Frontend

* ✅ Next.js 14 (App Router)
* ✅ Wallet connection using Wagmi + Viem
* ✅ Ethereum Sepolia integration
* 🚧 Live market interface (in progress)
